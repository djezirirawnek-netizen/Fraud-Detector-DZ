# 🛡️ Fraud-Detector-DZ

نظام ذكي لتحليل وكشف مخاطر الاحتيال في المعاملات المالية في الجزائر (بالدينار الجزائري دج) باستخدام Python و Flask.

## ✨ المميزات
- تحليل فوري لمخاطر المعاملات المالية بناءً على المبلغ، التوقيت، الموقع الجغرافي، ونوع المعاملة (محلية CIB/Edahabia أو دولية).
- حساب نسبة احتمالية الاحتيال وتوضيح أسباب وعوامل الخطورة بالتفصيل.
- حفظ وعرض سجل التحليلات السابقة تلقائياً باستخدام قاعدة بيانات SQLite.
- واجهة مستخدم متجاوبة تدعم اللغة العربية.

## 🚀 طريقة التشغيل
1. تثبيت المكتبات المطلوبة:
   `pip install -r requirements.txt`
2. تشغيل السيرفر:
   `python app.py`
